# LimeZu Asset Import Plan

## Boundary

LimeZu assets may be used in the compiled commercial game under the paid-pack licenses Julie owns. The original license files and purchase records stay with the local project materials.

## Do not commit

- Raw LimeZu PNGs, sprite sheets, generators, or editable source files
- Unmodified asset packs
- Any source package that would let a recipient extract and reuse the pack

## Planned import location

When the local paid pack files are available, copy only the selected production-ready art into a local, ignored path such as `assets/third_party/limezu/`. Keep the supplied license text outside the distributable game build and preserve a local copy for project records.

## First art pass

Select only what the first shop needs:

- Interior floors and walls
- Shelves, counter, register, doors, restroom, storage props
- A small set of customer sprites
- UI panels/buttons if needed
- Exterior entrance and parking/road pieces

Do not import the entire packs. The graybox must remain playable without them.

## Attribution

Include this in the in-game credits screen:

> Pixel art assets by LimeZu — https://limezu.itch.io/

The exact attribution should be checked against each included pack's current `LICENSE.txt` before release.
